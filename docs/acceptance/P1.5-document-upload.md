# P1.5 — Reusable document upload (acceptance)

**Scope:** Bulk upload to new and existing Hives via Web API → Edge Function `v1-documents` → public RPC → `hive3.source_documents` + private bucket + `upload_quota_events`.

## Operator prerequisites

1. Apply migrations in order (after prior P1.4 hive RPC migration if not already applied):
   - `supabase/migrations/20261021150000_hive3_m1_upload_baseline.sql`
   - `supabase/migrations/20261021150100_hive3_m1_public_document_rpc.sql`
2. Deploy Edge Function `supabase/functions/v1-documents` (requires `SUPABASE_SERVICE_ROLE_KEY` in function secrets).
3. Optional env: `SUPABASE_DOCUMENT_EDGE_FUNCTION=v1-documents`. Upload limits come from `hive3.upload_product_policy` (P1.6).

## Live checks

| # | Flow | Expected |
|---|------|----------|
| 1 | Signed-in user uploads 2 PDFs on existing Hive | Both appear in Documents list after refresh; quota decreases by 2 |
| 2 | Landing → select files → register → create Hive | Files upload automatically on workspace; draft cleared |
| 3 | 11th successful upload in UTC month | Prepare or complete returns quota message; no extra quota row |
| 4 | Wrong Hive id / other user | Access denied / not found |
| 5 | Oversize or .txt file | Validation error before storage write |

**Out of scope:** Inngest, Reader, Canonical Study, processing jobs.
