# P1.7 — Document workspace UX and permanent Hive deletion

**Status:** IMPLEMENTED (repo) — P1.7 deletion SQL applied and Edge `v1-hives` deployed at commit `52cb061`; **P1.7-A** adds My Hives card summary (`20261021180000_hive3_m1_hive_card_summary.sql`) + web UI; live browser acceptance pending.

## Scope delivered (repo)

- Documents tab aligned with prototype: document count, **Add documents**, compact list, type labels, upload dates, upload-only status badges (Uploading / Uploaded / Upload failed), quota + commercial offer preserved, partial-failure messaging and retry on failed rows.
- Owner-initiated **permanent Hive deletion** with modal title **Delete this Hive?**, exact lowercase `delete` confirmation, cancel with no side effects, navigate to My Hives after success.
- Backend: `deleting_at` gate, storage enumeration + service-role cleanup, verified empty prefix, `SECURITY DEFINER` finalize RPC (`hive3_m1_complete_hive_deletion` EXECUTE granted to `service_role` only; Edge `v1-hives` finalizes after storage verify), no `authenticated` DELETE on `hive3.hives`, idempotent retries via Edge Function `op: delete`.
- Recovery UX: Hives with incomplete deletion stay on **My Hives** with **Deletion incomplete** and **Retry deletion** (no typed confirmation); workspace and uploads remain blocked until finalize succeeds.
- **P1.7-A (repo):** My Hives cards show **Not identified yet.** for domain, registered document count, up to three newest filenames (`+N more`), description when stored, updated date, **Open Hive** / **Delete Hive** card menu (typed `delete` modal), and backward-compatible UI when card summary fields are absent pre-migration.
- **P1.7 upload recovery (repo):** Workspace **Your documents** count matches registered-only total (My Hives card); failed attempts in a separate section with persisted **Upload failed** status; **Dismiss** removes storage then soft-hides the row; prepare RPC rejects new uploads when quota is exhausted (retries unchanged); complete RPC still authoritative for quota events.
