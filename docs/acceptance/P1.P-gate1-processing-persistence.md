## Negative cases (required)

- **Idempotency cross-Hive:** delivery key bound to Hive A; enqueue from owner of Hive B with same key must **fail** (`idempotency_hive_mismatch`), never return Hive A’s run id.
- **Artifact hash conflict:** same `(study_run_id, artifact_kind, revision)` with different `content_sha256` → `artifact_revision_hash_conflict`; row unchanged.
- **Artifact hive binding:** `hive_id` on artifact always derived from run (trigger); worker cannot attach to another Hive by parameter.
- **Cross-owner read:** `hive3_p1p_get_study_run` / `get_intent` → `access_denied`.
