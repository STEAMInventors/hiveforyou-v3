# P2.1 — Reader document read (`reader-document-read@1`)

**Ticket:** P2.1 — Extraction Reader (page-grounded read)  
**Status:** IMPLEMENTED (repo) — local pytest + contracts typecheck verified (2026-10-22); blocked on Worker integration and Oracle deploy  
**Contract:** `packages/contracts/src/reader/v1`, `apps/reader` FastAPI `POST /v1/read-document`

## In scope (P2.1)

- Universal read artifact: per-page text, extraction method, quality indicators, source identity (`sha256`, storage path).
- PDF native text, PNG/JPG OCR (local Tesseract when installed), selective LiteLLM vision OCR when configured.
- DOCX `reproducible_v1`: headless LibreOffice DOCX → PDF, then shared PDF text pipeline; pinned LO version on Oracle (`READER_LIBREOFFICE_VERSION_PIN`).
- `POST /v1/read-document` requires `READER_SERVICE_TOKEN` Bearer auth (503 if unset; 401 if missing/invalid).
- Errors via `error-envelope@1`; correlation / run / batch headers propagated.
- P2.2 `extraction_schema` rejected with `INVALID_REQUEST`.
