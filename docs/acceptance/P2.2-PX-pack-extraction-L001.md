### 2.2 Negative and recovery

| # | Injected condition | Expected |
|---|---|---|
| N1 | One fact with unknown `fact_id` | That fact rejected `UNKNOWN_FACT_ID`; other facts preserved; disposition `VALID_WITH_REJECTIONS`. |
| N2 | One fact with wrong type / invalid enum | Fact rejected `TYPE_MISMATCH` / `ENUM_INVALID`; document usable. |
| N3 | `OBSERVED` fact with no anchor | Fact rejected `MISSING_EVIDENCE`; document usable. |
| N4 | Fabricated quote / wrong page | Fact rejected `QUOTE_NOT_IN_PAGE` / `PAGE_OUT_OF_RANGE`; document usable. |
| N5 | Record with unknown `record_type_id` | Record rejected `UNKNOWN_RECORD_TYPE`; other records preserved. |
| N6 | Classification names a type not in the pack | Document `UNUSABLE`; `MODEL_OUTPUT_INVALID` / `classification_invalid`; safe metadata persisted. |
| N7 | Response is not JSON | Document `UNUSABLE`; `MODEL_OUTPUT_INVALID` / `output_not_json`; `extraction_json` NULL; no raw text stored or logged. |

| N10 | Synthetic oversized document (prefix fits) | Mode B page windows with same `prompt_digest`; one batch per window. |
| N11 | Synthetic oversized pack | Mode C partition plan with completeness proof; or compile failure `EXTRACTION_FAILED` / `catalog_incomplete` if a single type cannot fit. No fact dropped. |
| N12 | No mode fits | `EXTRACTION_FAILED` / `context_budget_exceeded`; no model call. |
| N13 | Gateway 429 / 5xx | `MODEL_UNAVAILABLE`, retryable; no inline model retry. |
| N14 | Gateway timeout | `MODEL_TIMEOUT`, retryable; no inline model retry. |
| N15 | Extraction alias unset | `DEPENDENCY_UNAVAILABLE` / `alias_not_configured`; no call; no fallback alias. |
| N16 | Pinned pack missing / unreviewed / corrupt | `INVALID_REQUEST` at `plan_schema`; no model call. |
| N17 | `DB_TRANSIENT` on batch insert | ≤ 3 inline retries, then step failure. |
| N18 | `DB_OUTCOME_UNKNOWN` | Read back by idempotency key; no duplicate row. |
| N19 | Same batch key, different content hash | Conflict (`INVALID_REQUEST` / `batch_hash_conflict`); no overwrite. |
| N20 | Same `prompt_digest`, different system bytes | Hard failure (`prompt_digest_collision`). |
| N21 | Extraction JSON over the JSONB cap | Batch `FAILED`, `extraction_json` NULL, `EXTRACTION_FAILED` / `payload_too_large` (until ADR approves `PAYLOAD_TOO_LARGE`); no truncation; no Storage spill. |
| N22 | Usage block without cache fields | `cache_status = NOT_REPORTED`; extraction result identical to the cached case. |
| N23 | Cache miss on every request | Extraction and validation results identical to a cache-hit run; no retry. |
| N24 | Reuse attempt from a different Hive with identical source bytes | Not reused; new extraction (Hive-scoped). |
| N25 | Log capture during all of the above | No prompt text, page text, quotes, completions, filenames, intent, keys or tokens in logs or `error_reason`. |
